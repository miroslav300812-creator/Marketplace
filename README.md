# NEON MARKET

Фуд-маркетплейс: React-клиент + Node.js API + база данных.
Корзина, рецепты «в 1 свайп», бонусы NEON CLUB, оплата через LiqPay, доставка Новой Почтой / курьером / самовывоз, админка.

Первая версия (всё в одном HTML-файле) лежит в [`prototype/index.html`](prototype/index.html).

## Быстрый старт

Нужен Node.js 20+.

```bash
cp server/.env.example server/.env   # настройки (можно оставить как есть)
npm run setup                        # зависимости + база SQLite с демо-данными
npm run dev                          # API :4000 + сайт :5173
```

Откройте http://localhost:5173. Админка: http://localhost:5173/admin (или `Ctrl + Shift + A`), пароль из `ADMIN_PASSWORD` (по умолчанию `admin`).

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки с автоперезагрузкой |
| `npm test` | Тесты API (vitest) + проверка типов клиента |
| `npm run build` | Сборка сервера и клиента |
| `npm start` | Продакшн: один процесс отдаёт и API, и собранный сайт на `PORT` |
| `npm run db:reset -w server` | Пересоздать базу с демо-данными |

## Интеграции: моки и реальные API

Каждый сервис работает в одном из двух режимов. Если ключа в `server/.env` нет — включается встроенный мок, всё работает для демо. Если ключ есть — идут настоящие запросы. Текущий режим виден в логе при старте и в админке (Дашборд → Интеграции).

| Сервис | Ключи в `server/.env` | Где взять | Без ключа |
|---|---|---|---|
| **LiqPay** | `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY`, `LIQPAY_SANDBOX` | liqpay.ua → Кабинет → Настройки → API | Встроенный эмулятор оплаты с тестовыми картами |
| **Новая Почта** | `NOVAPOSHTA_API_KEY`, `NOVAPOSHTA_SENDER_CITY_REF` | new.novaposhta.ua → Настройки → Безопасность | 25 городов с генерируемыми отделениями и тарифом |
| **SMS Fly** | `SMSFLY_API_KEY`, `SMSFLY_SENDER` | sms-fly.ua → личный кабинет | Код показывается во всплывающем «SMS» на сайте |

Что нужно знать при подключении:

- **LiqPay.** Покупатель уходит на страницу оплаты LiqPay; Apple Pay / Google Pay выбираются там же. Результат приходит на `API_URL/api/payments/liqpay/callback` — этот адрес должен быть доступен из интернета (на локальной машине — через туннель, например ngrok). Подпись колбэка и сумма проверяются. С `LIQPAY_SANDBOX=1` деньги не списываются.
- **Новая Почта.** Используются `searchSettlements`, `getWarehouses`, `getDocumentPrice` и `getDocumentDeliveryDate`. `NOVAPOSHTA_SENDER_CITY_REF` — город, откуда вы отправляете (по умолчанию Киев).
- **SMS Fly.** Имя отправителя (`SMSFLY_SENDER`) должно быть зарегистрировано в SMS Fly. Формат запроса взят из документации API v2 — проверьте его на своём аккаунте первой отправкой.
- **Бонусы.** Программа лояльности ведётся в собственной базе (баланс, история, уровни, кэшбэк). Внешнего API (Motive Force / ABM) нет — для него нужна их документация.
- **Карта** магазинов и зоны курьерской доставки — собственная SVG-схема Киева, без Google Maps.

Тестовые карты эмулятора: `4242 4242 4242 4242` — успех, `4000 0000 0000 3220` — с 3-D Secure, `4000 0000 0000 0002` — отказ. Промокоды: `EXTRA20`, `FREE_DELIVERY`, `NEON100`.

## Как устроено

```
server/                 Express 5 + Prisma + SQLite (TypeScript)
  prisma/schema.prisma  модель данных; seed.ts — демо-каталог
  src/lib/pricing.ts    расчёт заказа: скидки наборов, промокоды, бонусы, доставка, остатки
  src/integrations/     LiqPay, Новая Почта, SMS Fly (реальный клиент + мок)
  src/routes/           каталог, вход по SMS, заказы, оплата, отзывы, админка
  test/api.test.ts      тесты API
client/                 React 19 + Vite + Tailwind 4 + Zustand
  src/components/       витрина, корзина, оформление, оплата, карта, лояльность
  src/pages/admin/      админ-панель
prototype/              исходная однофайловая версия
```

Главное правило: **суммы считает только сервер.** Клиент показывает цены, но при оформлении сервер заново проверяет товары, остатки, промокод, лимит бонусов (не больше 50% чека) и стоимость доставки. Остатки и бонусы списываются атомарно, при отмене заказа возвращаются. Кэшбэк начисляется после оплаты (или при выдаче — для оплаты при получении).

Вход покупателя — по номеру телефона и SMS-коду (JWT на 30 дней). Код хранится хэшем, есть лимиты: повтор через 60 с, не больше 5 кодов в час и 5 попыток ввода.

## Перед запуском в продакшн

1. `JWT_SECRET` — длинная случайная строка, `ADMIN_PASSWORD` — надёжный пароль (сервер не стартует в `NODE_ENV=production` с дефолтными значениями).
2. `PUBLIC_URL`, `API_URL`, `CORS_ORIGIN` — ваши настоящие адреса (https).
3. Для реальной нагрузки перейдите на PostgreSQL: в `schema.prisma` поменяйте `provider = "postgresql"`, укажите `DATABASE_URL` и выполните `cd server && npx prisma db push`.
4. `npm run build && npm start` за reverse-proxy с HTTPS (nginx, Caddy) или на платформе вроде Render / Railway / Fly.io.
